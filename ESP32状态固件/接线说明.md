# 接线说明

按这张表接线，**不需要改任何代码**，直接用「固件烧录」页烧进去就能用。
接法和这里不一样，就要改对应固件里的一行 `#define`，具体见最后一节。

系统共 5 块 ESP32：1 块 Master 插电脑，4 块 Slave 用电池供电，通过 ESP-NOW 无线发给 Master。

---

## 一览表

| # | 板子 | 接什么 | 接到哪个脚 |
| --- | --- | --- | --- |
| 1 | **Master** | 什么传感器都不接，只插 USB 到电脑 | — |
| 2 | **Finger** | PPG 传感器 ×1 | 信号 → **GPIO35** |
| 3 | **Wrist** | PPG 传感器 ×1 + 六轴 IMU ×1 | PPG 信号 → **GPIO35**<br>IMU SDA → **GPIO21**，SCL → **GPIO22** |
| 4 | **Other** | PPG 传感器 ×1（对照通道） | 信号 → **GPIO35** |
| 5 | **Wheel** | 六轴 IMU ×1 | SDA → **GPIO21**，SCL → **GPIO22** |

四块 Slave 的**接法完全对称**：PPG 一律接 GPIO35，IMU 一律接 GPIO21/22。
所以同一块板烧哪个固件就是哪个角色，硬件不用动。

---

## 每个传感器的完整接线

### PPG 传感器（Finger / Wrist / Other）

用的是 **Pulse Sensor Amped** 这类**模拟输出**的光电脉搏传感器，三根线：

| 传感器引脚 | 接到 ESP32 |
| --- | --- |
| VCC（红） | **3V3** |
| GND（黑） | **GND** |
| Signal（紫） | **GPIO35** |

> ⚠️ 必须是**模拟输出**的 PPG。像 MAX30102 那种 I²C 数字输出的传感器**不能直接用**，代码读的是 `analogRead()`。

### 六轴 IMU（Wrist / Wheel）

I²C 接口，四根线：

| IMU 引脚 | 接到 ESP32 |
| --- | --- |
| VCC | **3V3** |
| GND | **GND** |
| SDA | **GPIO21** |
| SCL | **GPIO22** |

代码按这个规格读 IMU，**换别的型号必须对得上**：

- I²C 地址：**0x23**
- 加速度三轴起始寄存器：**0x04**（连读 6 字节）
- 角速度三轴起始寄存器：**0x0A**（连读 6 字节）
- 数据格式：int16，低字节在前

> ⚠️ MPU6050 的地址是 0x68、寄存器也不一样，**直接换上去读不出数据**。要用别的 IMU 得改 `IMU_ADDR` 和两个寄存器地址。

### 电池（可选，默认关闭）

固件里默认 `BATTERY_MONITOR_ENABLED 0`，**不接分压线也能正常工作**，只是 GUI 上电量显示「未配置」。

想看电量，先接 1:2 分压（两个等值电阻，精度 1%）：

```
电池正极 ──[100kΩ]──┬──[100kΩ]── GND
                    │
                  GPIO34
```

> ⚠️ 电池电压**不能直接接** ESP32 引脚，会烧坏。必须分压。

接好后把对应固件改成：

```cpp
#define BATTERY_MONITOR_ENABLED 1
```

电阻比例不是 1:2 的话，同时改 `BATTERY_DIVIDER_RATIO`。第一次用建议拿万用表量一下真实电压，对照 GUI 显示校正比例。

## 板子本身的要求

- **必须有 GPIO35**（PPG 那三块）。经典 ESP32、ESP32-S2、ESP32-S3 都有；
  **ESP32-C3 / C6 物理上只有 GPIO0–21，没有 35**，不能拿来做 PPG 从机，只能做 Wheel（它只用 21/22）。
- USB 线必须是**能传数据**的，很多充电线只有电源线。
- 烧录时**一次只插一块板**，其他的拔掉。
- 串口波特率固定 **115200**。

## 引脚和我不一样怎么办

改对应固件里的一行，改完直接烧，**不用重启程序**。
GUI「固件烧录」页有「打开固件源码」按钮，点了直接到这个目录。

| 想改什么 | 改哪个文件 | 改哪一行 |
| --- | --- | --- |
| Finger 的 PPG 引脚 | `02-finger-monitor.ino` | `#define FINGER_PPG_PIN 35` |
| Wrist 的 PPG 引脚 | `03-wrist-monitor.ino` | `#define WRIST_PPG_PIN 35` |
| Other 的 PPG 引脚 | `04-other-monitor.ino` | `#define OTHER_PPG_PIN 35` |
| IMU 的 SDA/SCL | `03-wrist-monitor.ino`<br>`05-wheel-monitor.ino` | `#define SDA_PIN 21`<br>`#define SCL_PIN 22` |
| IMU 型号/地址 | 同上 | `#define IMU_ADDR 0x23`<br>`#define REG_ACCEL_X_L 0x04`<br>`#define REG_GYRO_X_L 0x0A` |
| 电池检测引脚 | 四个 Slave 各自 | `#define BATTERY_ADC_PIN 34` |

换 PPG 引脚时注意：ESP32 上 **GPIO32–39 属于 ADC1**，WiFi 开着也能用；
**GPIO0/2/4/12–15/25–27 属于 ADC2，开 WiFi 后读不了**——而这套系统全程开着 ESP-NOW（就是 WiFi），所以 **PPG 只能接 ADC1 的脚**。

> `uint8_t receiverMac[] = {...}` 这一行**不要动格式**。烧录时程序会自动把它替换成当前 Master 的 MAC，值是多少无所谓，但变量名和大括号的写法不能变，否则注入会失败并中止烧录。

## 采样节奏（一般不用改）

| 板子 | 节奏 |
| --- | --- |
| Finger | 每 21 ms 发一次 |
| Other | 每 23 ms 发一次 |
| Wheel | 每 27 ms 发一次 |
| Wrist | 每 40 ms 发一次 |
| Master | 每 **48 ms** 汇总输出一行（20.83 Hz），每 500 ms 额外发一条 `@STATUS` |

几块 Slave 故意用了**互不相同的间隔**，避免它们总在同一时刻抢发、互相碰撞丢包。

Master 输出的每一行是「各通道最近收到的值」的快照，不保证所有传感器在同一物理时刻采样——做时序分析时要记得这一点。
